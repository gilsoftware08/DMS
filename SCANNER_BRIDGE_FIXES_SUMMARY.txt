3. CONFIGURATION
================================================================================

ENVIRONMENT VARIABLE:
  Variable Name: NEXT_PUBLIC_SCANNER_BRIDGE_URL
  Default Value: http://localhost:4785
  Scope: NEXT_PUBLIC (accessible in browser, safe)
  Purpose: Configure scanner bridge endpoint
  Example Values:
    • http://localhost:4785 (local development)
    • http://192.168.1.100:4785 (network machine)
    • https://scanner-bridge.company.com (production)

SETUP STEPS:

1. Create .env.local file in project root (if not exists):
   ─────────────────────────────────────────────────────────
   DATABASE_URL="sqlserver://..."
   JWT_SECRET="your-secret-key-32+-characters"
   NEXT_PUBLIC_SCANNER_BRIDGE_URL="http://localhost:4785"
   NODE_ENV="development"

2. Or copy from template:
   ─────────────────────────────────────────────────────────
   cp .env.local.example .env.local

3. Edit .env.local with your scanner bridge URL

4. Restart Next.js dev server:
   ─────────────────────────────────────────────────────────
   npm run dev

4. COMPLETE API FLOW (DIAGRAM)
================================================================================

USER CLICKS "SCAN NOW"
         ↓
  handleScanNow() in page.tsx
         ↓
  toast.loading("Connecting...")
         ↓
  scanDocument() from lib/scanner.ts
         ├─→ Validates environment variable
         ├─→ Creates AbortController (60s timeout)
         ├─→ POST to ${NEXT_PUBLIC_SCANNER_BRIDGE_URL}/scan
         └─→ Logs: [Scanner] Starting scan
         ↓
  Bridge receives request
         ↓
  Bridge triggers scanner hardware
         ↓
  Hardware scans document (10-30 seconds)
         ↓
  Bridge converts to PDF + Base64 encodes
         ↓
  Bridge returns JSON:
         {
           "success": true,
           "fileData": "base64_encoded_pdf",
           "extension": "pdf",
           "fileName": "document.pdf",
           "scannedAt": "2026-05-09T..."
         }
         ↓
  scanDocument() validates response
         ├─→ Checks: res.ok, data.success, data.fileData
         ├─→ Logs: [Scanner] Scan response received
         └─→ Returns ScanResponse object
         ↓
  handleScanNow() calls convertScanResponseToFile()
         ├─→ Decodes Base64 → binary string
         ├─→ Creates Uint8Array from characters
         ├─→ Creates Blob from bytes
         ├─→ Creates File with timestamp: scanned-{ISO-time}.pdf
         └─→ Logs: [Scanner] File created from scan
         ↓
  handleScanNow() calls processPdfFile(file, 'Scanned Document')
         ├─→ Imports pdfjs-dist
         ├─→ Renders all pages as PNG thumbnails
         ├─→ Stores in IndexedDB (localforage)
         └─→ Shows: "Scanned Document loaded with X pages"
         ↓
  User sees thumbnail grid
         ├─→ Selects pages
         ├─→ Enters section name
         └─→ Clicks "Save Section"
         ↓
  Standard PDF upload workflow continues
         ├─→ pdf-lib extracts selected pages
         ├─→ File saved to /public/uploads/{folder}/
         └─→ Document record created in database

ERROR HANDLING AT EACH STAGE:

❌ Bridge Offline:
   ├─ Catch: TypeError (connection refused)
   ├─ Error Code: 'OFFLINE'
   ├─ Message: "Scanner bridge offline - ensure the desktop app is running on port 4785"
   └─ Toast: Shows for 5 seconds

❌ Timeout (60 seconds exceeded):
   ├─ Catch: DOMException with name 'AbortError'
   ├─ Error Code: 'TIMEOUT'
   ├─ Message: "Scan timeout - is paper in the scanner? Make sure you loaded the document."
   └─ Logs: [Scanner] Scan timeout triggered

❌ Invalid Response:
   ├─ Response not JSON or missing fields
   ├─ Error Code: 'INVALID_RESPONSE' or 'SCAN_FAILED'
   ├─ Message: "Scanner returned invalid response"
   └─ Logs: [Scanner] Response status and body

❌ Conversion Error:
   ├─ atob() fails or File creation fails
   ├─ Error Code: 'CONVERSION_ERROR'
   ├─ Message: "Failed to convert scanned document to file"
   └─ Logs: [Scanner] Detailed error info

8. CODE EXAMPLES
================================================================================

EXAMPLE 1: Using scanner helper directly (advanced)
──────────────────────────────────────────────────────

import { scanDocument, getScannerStatus, ScannerError } from '@/lib/scanner';

// Check if bridge is online
try {
  const status = await getScannerStatus();
  if (status.online && status.scanners.length > 0) {
    console.log('Ready to scan with:', status.scanners[0].name);
  }
} catch (error) {
  console.error('Bridge offline');
}

// Perform scan with options
try {
  const scanResponse = await scanDocument({
    scannerId: 'scanner-1',
    resolution: 300,
    colorMode: 'color'
  });
  console.log('Scanned successfully:', scanResponse.fileName);
} catch (error) {
  if (error instanceof ScannerError) {
    console.error(`[${error.code}] ${error.message}`);
  }
}

EXAMPLE 2: Custom error handling
──────────────────────────────────

import { scanDocument, getScannerErrorMessage, ScannerError } from '@/lib/scanner';

try {
  await scanDocument();
} catch (error) {
  const message = getScannerErrorMessage(error);
  
  // Show in custom toast library
  showNotification({
    type: 'error',
    title: 'Scan Failed',
    message: message,
    autoClose: 5000
  });
  
  // Log for analytics
  trackEvent('scan_failed', { error: error.code });
}

11. TROUBLESHOOTING QUICK REFERENCE
================================================================================

SYMPTOM: "Cannot find NEXT_PUBLIC_SCANNER_BRIDGE_URL"
CAUSE: Environment variable not set
FIX: Add to .env.local and restart server

SYMPTOM: "Scanner bridge offline" every time
CAUSE: Bridge URL wrong or bridge not running
FIX: Check bridge URL in .env.local
     Verify bridge is running: curl $NEXT_PUBLIC_SCANNER_BRIDGE_URL/status

SYMPTOM: Scan works locally but fails in production
CAUSE: Environment variable not set in production
FIX: Add NEXT_PUBLIC_SCANNER_BRIDGE_URL to production env vars
     Must be NEXT_PUBLIC_ prefix to be visible in browser

SYMPTOM: "Scan timeout" even with paper loaded
CAUSE: Scanner hardware issue or network timeout
FIX: Check scanner hardware
     Check network latency to bridge
     Increase timeout in lib/scanner.ts (SCAN_TIMEOUT_MS)

SYMPTOM: Blank error message after scan
CAUSE: Bridge returned invalid response
FIX: Check bridge logs for error
     Verify bridge version compatibility
     Check browser console for [Scanner] debug output
